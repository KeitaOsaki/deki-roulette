# 出来レーレット

ユーザが入力した項目をルーレットに追加し、追加された項目の中から必ず1つを選ぶシングルページアプリケーションです。

## コンセプト

「ルーレットで決めたことにしたい」というシーンで使うツールです。
ルーレットを回す前にユーザが**当てたい項目をあらかじめ指定**しておくことで、見た目はルーレットが回るものの、結果は意図した項目に必ず止まります。
ランダムではなく、**ユーザの意図を結果として演出する**ことがこのサービスのメイン機能です。

## 機能

- 項目を自由に追加・削除
- 追加した項目を円グラフ状のルーレットに表示
- スピン前に当てたい項目をあらかじめ指定
- スピンボタンでルーレットを回転し、**指定した項目に必ず止まる**
- 選択結果を画面上に表示

## ローカル起動

### 前提

- Node.js 18 以上
- npm

### 手順

```bash
# 依存関係のインストール
npm install

# 開発サーバの起動 (http://localhost:5173)
npm run dev
```

### その他のコマンド

```bash
# 本番ビルド
npm run build

# ビルド結果のプレビュー (http://localhost:4173)
npm run preview

# Lint
npm run lint
```

## デプロイ

`main` ブランチへのプッシュで Cloudflare Pages が自動的にビルド＆デプロイします。

| 設定項目 | 値 |
|---|---|
| Build command | `npm run build` |
| Build output directory | `dist` |
