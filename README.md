# 出来レーレット

ユーザが入力した項目をルーレットに追加し、追加された項目の中から必ず1つを選ぶシングルページアプリケーションです。

## コンセプト

「ルーレットで決めたことにしたい」というシーンで使うツールです。
回す前に当てたい項目を指定しておくと、見た目はランダムに回りながら結果はその項目に止まります。

人に画面を見せながら回す状況を前提にしているため、**仕込めることが画面上から一切分からない**設計になっています。表向きはただのルーレットで、当たりの指定は隠しジェスチャからのみ行えます。

## 機能

- 項目を自由に追加・削除（2〜24 個）
- 追加した項目を円グラフ状のルーレットに表示
- スピンボタンでルーレットを回転し、結果を表示
- 項目の長押しで、次のスピンで選ばれる項目を指定
- 日本語版 `/` と英語版 `/en/` の言語別 URL、`prefers-reduced-motion` 対応

### 当たりの指定

項目を 0.6 秒ほど長押しすると、その項目が次のスピンで選ばれます。もう一度長押しで解除。
キーボードの場合は項目にフォーカスして Enter を押しっぱなしにします。単純なクリックやタップでは何も起きません。

指定中の印はカラードットが中抜きのリングに変わるだけで、次の条件でのみ表示されます。

- リストにポインタまたはフォーカスがある間
- 指定した直後の約 1.6 秒間

スピン中と結果表示中は必ず伏せられ、フッターの「使い方」もスピンを押した瞬間に自動的に閉じます。
何も指定しなければ結果は本当にランダムです。

## ローカル起動

### 前提

- Node.js 18 以上
- npm

### 手順

```bash
# 依存関係のインストール
npm install

# 開発サーバの起動 (http://localhost:5173)
npm run dev
```

### その他のコマンド

```bash
# 本番ビルド
npm run build

# ビルド結果のプレビュー (http://localhost:4173)
npm run preview

# Lint
npm run lint
```

|---|---|
| Build command | `npm run build` |
